## Quick Reference

**Stack:** Next.js 15 + TypeScript + Tailwind v4 + shadcn/ui + Neon Postgres + Drizzle ORM + Auth.js v5

**Timeline:** 8 weeks to launch (6 dev + 2 launch)

**Business:** AGPL-3.0, Free tier + Pro ($4/mo) + Family ($8/mo)

**Launch:** Reddit (r/selfhosted) → Dev.to → HN → Product Hunt
